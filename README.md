# Website SMA Sugar Group

Landing page profil sekolah SMA Sugar Group (Lampung Tengah) dengan HTML, CSS, dan JavaScript murni.

## Fitur
- Navbar sticky + menu hamburger di mobile
- Hero slider otomatis
- Profil, visi & misi, program unggulan, fasilitas, galeri
- Kontak, peta lokasi, footer, dan tombol kembali ke atas
- Responsif (desktop, tablet, HP)

## Struktur
```
index.html
css/style.css
js/main.js
assets/images/
```

## Cara menjalankan
1. Buka folder di VS Code.
2. Install ekstensi **Live Server**.
3. Klik kanan `index.html` → **Open with Live Server**.

## Mengganti konten
- Foto: taruh di `assets/images/` dengan nama `hero-1.jpg`, `gallery-1.jpg`, dst.
- Teks: edit langsung di `index.html` (cari tulisan "Placeholder").
- Warna: ubah variabel di bagian `:root` pada `css/style.css`.
- Link sosmed: ganti `href="#"` di `index.html`.
